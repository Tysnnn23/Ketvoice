Infrastructure

Toutes les API, par catégorie

Les bases éditables exigent le même contrat JSON que le fournisseur d’origine. Elles sont validées côté serveur et récupérées par la nouvelle app au démarrage puis toutes les 5 minutes. Les médias déjà en cache ne sont pas effacés. Aucun état « disponible » n’est déduit d’une simple activation.

Ajouter une musique

Uniquement des médias dont vous possédez les droits. Audio 25 Mo maximum ; pochette 4 Mo ; paroles LRC ou TTML 1 Mo.

Rechercher et modifier

La recherche affiche les titres publiés ; seule une musique importée par votre compte peut être modifiée. Les titres du catalogue général ne sont pas éditables.

Importer des paroles

Publiez une version LRC ou TTML pour une musique, y compris un titre du catalogue. Une nouvelle version est ajoutée sans modifier l’audio.

Albums

Recherchez un album publié, changez son Canvas pour tout l’album ou titre par titre, et ajoutez ou retirez des titres. Le Canvas est la vidéo jouée derrière les paroles dans l’application.

Manifestes de sources

Ces manifestes HTTPS sont testés puis enregistrés dans le Studio. Le courtier actuel ne les utilise pas automatiquement : pour les utiliser immédiatement, ajoutez-les dans Sources personnalisées sur chaque appareil. L’ordre ci-dessous est un ordre de gestion, pas une priorité globale de lecture. Pour les services intégrés réellement pilotables à distance, utilisez « API par catégorie ».

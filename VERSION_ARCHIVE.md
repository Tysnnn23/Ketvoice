# Ketvoice 1.0.0 — binary archive

This tag exists only to host the archived **Ketvoice 1.0.0** APK variants as GitHub release assets.

The source snapshot for 1.0.0 was not preserved. The current source code is on the `main` branch and corresponds to the latest release. These legacy APKs are provided for reference only and are not supported.

See the repository [README](https://github.com/Tysnnn23/Ketvoice) and [CHANGELOG](https://github.com/Tysnnn23/Ketvoice/blob/main/CHANGELOG.md) for the current project.

# Ketvoice 3.0.0-Beta1 🚀

The first beta of the big 3.0! This one is all about depth, glass and personal music.

## ✨ New
- **Local Music** 🎵 — browse and play the audio files stored on your device, fully integrated with the player, queue and favorites.
- **Liquid Glass back buttons** 🧊 — every sub-screen (Artist, Catalog, Downloads, Local Music, Settings) now closes with a beautiful frosted-glass back button instead of a flat icon.
- **Tablet swipe-to-close** 👋 — on tablets and landscape layouts, swipe the full player sideways to dismiss it, with a live drag animation.
- **Crisp artist banner** 🎨 — the artist page header is sharper and more immersive than ever.
- **2x2 mosaic covers** 🖼️ — playlists and albums with multiple tracks now show a beautiful mosaic of the first four artworks.

## 🛠 Improved
- Smoother player gestures and animations across the board.
- Settings reorganized into clearer sections.

## 🐛 Fixed
- Duplicate import and nullability crashes in the library screen.
- Various stability fixes in the queue and catalog.

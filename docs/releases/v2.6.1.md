# Ketvoice 2.6.1

**Android 12+ · versionCode 14 · 22 October 2026**

## Publisher email login fix

- Open a newly requested email login link on the device running Ketvoice. Supabase now redirects to **`ketvoice://auth`**, not localhost, and Ketvoice opens the publisher screen automatically.
- Cold-start and already-running app links are supported. When Android offers Ketvoice for the original Supabase verification URL, the app can also verify that link directly.
- The manual paste fallback is fixed: the `token` in a Supabase email URL is a **token hash**, not a numeric email OTP. Numeric codes remain supported if an email provider supplies one. Pasted links are masked; numeric codes remain readable.
- Callback identity and expiry are not trusted. A callback refresh token is exchanged for a server-validated session, and the publication broker must approve the confirmed publisher mailbox before access is enabled. Authorization on every write is unchanged.
- Strict callback URL/parameter validation rejects foreign hosts, unexpected ports/paths, duplicate parameters, malformed encoding, and oversized links. Callback credentials are not retained in the Activity launch intent or copied into the input field.
- Updated instructions are bundled in all 11 interface languages. French remains the default. Tablet layouts, Liquid Glass, song search, and public song/lyrics behavior are unchanged.

## Use it

1. Install **`Ketvoice-2.6.1.apk`** over the existing app.
2. Request a **new** login link from the publication screen.
3. Open that email's link on the **same device**. Choose Ketvoice if Android asks. The app checks your access automatically.
4. If your email client does not reopen Ketvoice, request a fresh link and paste the original email link into the app without opening it first.

Older emails may still contain a localhost redirect or an already-used token. Do not reuse them. Only the verified **konnektsupport@gmail.com** mailbox can publish; a matching YouTube profile is not authorization.

## Limitations

- Mailbox access is unavailable to development. Delivery of a real email and completion of the mailbox owner's login still require the owner; emulator tests use synthetic invalid callbacks, not a real publisher session.
- This is the **direct-link option**, not code-only email. Supabase's free/default email provider blocks custom email templates; code-only delivery needs custom SMTP or an eligible paid plan. No SMTP credentials or paid plan were added.
- Default Supabase email rate limits still apply. Mail-client handling of custom schemes varies; the manual original-link fallback remains available.
- The custom scheme is not a domain-verified Android App Link. Use only the expected Ketvoice app when Android offers a choice.
- Published media remains public and consumes the project's storage/egress quotas.

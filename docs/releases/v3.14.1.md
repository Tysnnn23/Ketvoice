# Ketvoice 3.14.1

![Ketvoice](https://raw.githubusercontent.com/Tysnnn23/Ketvoice/main/ketvoice-banner.png)

## Playlist correction

- Remove the leftover scroll-driven opacity from the fixed playlist header. The artwork, title and controls now remain visible rather than fading into an empty reserved area.
- Use a compact, side-by-side header in short windows, leaving room for the track list on landscape Mobile and Quest.
- Correct track-reordering indices after the header was moved out of the list, keep the dragged row's index current, and serialize pending moves.

## Ketvoice Studio

- Add an overview with anonymous active-listening counts, provider inventory and the owner's published album count. These are not identified user accounts or fabricated health checks.
- Search actual tracks, albums and artists from the same YouTube Music catalogue used by Android, plus Ketvoice API tracks and publications. Open album/artist tracks with native catalogue identifiers. Provider outages are reported without inventing results; catalogue presence does not guarantee stream availability.
- Inspect all 30 registered service integrations by category. Ten public JSON adapters support enable/disable and compatible HTTPS base overrides; two streaming brokers have app-side activation switches. Authentication, private-key brokers, SDKs and update trust anchors remain protected and explain why code deployment is required.
- New app builds fetch the validated configuration at startup and every five minutes, retaining the last valid cached rules if offline. Public adapter changes apply to fresh requests, not already cached media. No user credentials are forwarded to replacement endpoints.
- Keep owner-only import metadata/audio/cover/Canvas editing and album Canvas management. General-catalog media cannot be replaced; authorized lyric versions can still be published. Artist names on owned publications can be changed in the track editor; general artist profiles are consultable, not remotely overwritten.
- Preserve edited API drafts when filtering, detect conflicting saves from another computer, persist refreshed remembered-session tokens, and explain local token storage accurately. Improve narrow-screen navigation and keyboard focus visibility.
- Correct the managed-manifest description: Studio stores their management order, but the current broker does not automatically consume them. Add a manifest on each device to use it immediately; integrated public adapters use the separate, connected configuration panel.

## Validation scope

- Android JVM and native host-render tests include fixed-header coordinates/pixels after scrolling, short landscape layout and a real drag gesture. They are software-host checks, not physical phone or Quest validation.
- Deno tests exercise normalization, protected endpoints, verified-owner checks, invalid configuration and concurrent-save conflicts.
- Browser checks exercise the dashboard with intercepted, mocked authentication/API responses, including saving/filtering settings, catalogue-to-lyrics actions, session refresh, logout and desktop/mobile layout. They do not constitute a real owner session.
- Direct live catalogue requests verify real upstream search and album browsing. Signed Mobile and Quest builds, lint, credential scanning and downloaded release hashes are checked before publication.
- Physical installation/playback, real owner uploads/settings changes, Discord OAuth/presence and restored upstream lossless access remain unvalidated. The glow threshold remains **870 ms**; group listening is not added.

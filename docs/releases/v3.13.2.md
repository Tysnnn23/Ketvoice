# Ketvoice 3.13.2

![Ketvoice](https://raw.githubusercontent.com/Tysnnn23/Ketvoice/main/ketvoice-banner.png)

## Discord linking

- Returning to Ketvoice without an authorization code now cancels the pending
  link after **8 seconds** instead of leaving "Connecting to Discord…" forever.
- Authorization opens the **Discord app first**, which reuses the signed-in
  session and delivers the redirect as an intent (custom-scheme navigation inside
  a browser or the Discord web view can hang). The browser remains the fallback
  when the Discord app is unavailable.
- The 3-minute absolute timeout, local `state` validation and the explicit
  `invalid_client` hint remain.

## Equalizer

- The equalizer is back in the track's three-dot menu, next to Reverb.
- The dialog now lists the device's real native bands and their centre
  frequencies, and adds a **Reset** action that returns every band to 0 dB.
- Presets and per-band sliders keep driving the real audio session through the
  native effect.

## Reverb

- Rebuilt as a proper Freeverb-style room: eight damped parallel combs and four
  all-pass diffusers per channel, stereo spread, an 18 ms pre-delay and a DC
  blocker.
- Three controls in the track menu: **Intensity**, **Room size** and **Damping**,
  with a **Reset** preset (35 % / 50 % / 35 %). Settings persist across restarts.
- The wet path is smoother and longer without the sub-bass rumble of the previous
  single-feedback design.

## Validation

- Host unit tests cover the reverb tail/stereo isolation and the payload rules;
  the equalizer and reverb UI are compiled and linted.
- **Not device-validated**: no phone, Quest or accelerated emulator is available
  here, so the Discord return tick, the authorization hand-off and the audible
  reverb/equalizer changes must be confirmed on the owner's phone.

# Ketvoice 4.8.0

![Ketvoice](https://raw.githubusercontent.com/Tysnnn23/Ketvoice/main/ketvoice-banner.png)

## Playback and source choice

- Ordered network resolution follows the configured source priority; existing downloads and suitable cached audio remain available. Progressive mode starts an available source and may upgrade it later. When lossless is prioritized online, a lossy streaming cache is held as a fallback rather than silently taking precedence.
- After restarting the app, the last saved queue, duplicate entries, position and playback modes are restored paused. Pressing Play resolves the selected track; the app does not automatically start audio.
- Search displays results as providers answer. Confident recording matches are grouped and offer provider buttons; explicit source choices are tried first while respecting disabled sources and allowing fallback.
- Optional audio statistics show the selected decoder's format and known provider, with an HTTP status when applicable. Provider labels are not proof of bit-perfect output or of source provenance.

## Personal library and lyrics

- Export a versioned personal backup and preview it before importing. Existing playlists are not replaced; favorites and history merge. Saved non-sensitive settings replace the corresponding settings on this device. An interrupted import can leave already-merged additions in place and reports an error.
- Accounts, credentials, custom-source configurations, sensitive consent settings, artwork and audio files are excluded. A recognized public Spotify playlist URL is kept without its query string. Local media permissions may need to be granted again on another device. Per-track lyric offsets are included as hashed identifiers.
- Adjust lyric timing per track in the lyrics source sheet; the adjustment applies to synchronized lines, word highlights, translated lines and lyric seeking without modifying the provider's timings.
- Home uses available local listening history and favorites to favor familiar artists and reduce recent repeats. Existing optional YouTube Music personalization is retained.

## Restricted offline DASH

- A separate non-evicting download cache supports finite, single-period, single-representation, unprotected FLAC DASH using the stable Ketvoice Lossless proxy when the source explicitly declares `allowDownloads`. Downloaded ranges are checked before an item is shown as ready. Playback of these downloads uses a read-only offline data source; clearing the streaming cache does not delete them.
- The current Ketvoice Lossless manifest does **not** declare download permission. Its DASH downloads remain disabled until the source operator explicitly grants permission and the manifest is refreshed. Other DASH layouts and protected streams are not supported; no DRM is bypassed. A paused partial download with expired segment URLs may need to be cancelled and retried. Cached manifests can contain temporary segment URLs in app-private storage; they are not included in personal backups or logs.

## Compatibility and validation limits

The signed Mobile and Quest APKs include the existing Discord integration. Local files, normal downloads, streaming cache, Canvas, karaoke, Bit-Perfect settings, the restored player/navigation and the Quest landscape 2D layout are retained. Eleven interface languages remain available. Group listening remains deferred.

The owner requested publication with Discord after being informed that no phone or Quest was connected. JVM/Robolectric tests, synthetic offline fixtures, lint, signatures and checksums do **not** prove audible playback, real DASH decoding, system-picker behavior, real Discord authorization, USB bit-exact output, GPU rendering or physical Quest behavior. No fixed startup time or frame rate is claimed. The Lossless keep-alive remains best effort while the app process is alive and can be deferred by Android.

For update compatibility these APKs use the existing public Android debug signing identity, not a private production signing key. Never uninstall an existing installation to resolve a signature conflict without backing up its data.

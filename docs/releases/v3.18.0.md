# Ketvoice 3.18.0

![Ketvoice](https://raw.githubusercontent.com/Tysnnn23/Ketvoice/main/ketvoice-banner.png)

A design-system pass that consolidates the premium look into shared, reusable
primitives. No behaviour changes to playback, sources, Discord or publications.

## Shadows & reflections

- **One elevation ladder** now drives every glass shadow, so surfaces read at
  consistent depths: content card 1 dp → round button 4 dp → floating pill and
  navigation 8 dp → bottom sheet 16 dp. Dark mode deepens the shadow alpha
  (×1.35) so frosted panels still detach from a near-black page.
- **Static glass gets a real drop shadow.** When Liquid Glass is disabled or a
  panel is captured, it used to render with no outer shadow and read as a flat
  painted rectangle. It now casts a diffuse, theme-aware lift.
- **Shader reflections improved (Android 13+ / AGSL).** A new diagonal specular
  band sweeps the light from the top-left toward the centre — the glass now
  reads as a tilted slab instead of a flat vertical sheen — and a faint bounce
  halo at the bottom-right mimics light passing *through* the block. The
  existing Fresnel rim, lens-edge refraction with chromatic dispersion,
  thickness shadow and caustic are unchanged.

## Coherent animations

- All durations, curves, springs and elevations now live in a single
  `Motion` object. A named scale (`FAST` 150 · `NORMAL` 250 · `MEDIUM` 350 ·
  `SLOW` 500 · `EPILOGUE` 700 ms), four easing curves, three named springs and
  a six-step elevation ladder replace scattered magic numbers.
- The historical API (`FADE`, `PRESS`, `duration()`, `pressSpring()`,
  `reduced`) is preserved, so every existing call site keeps working unchanged.
- Reduce-motion (system setting or in-app toggle) still collapses everything to
  instant.

## Automatic contrast

- New contrast helpers choose ink and tint from the real backdrop luminance, so
  labels drawn over album art stay readable in light and dark themes. Includes a
  WCAG contrast-ratio check (4.5:1 threshold), a blend helper that preserves
  alpha, and an `adaptSurface` that nudges the glass tone away from the backdrop
  so material and content never dissolve into each other.

## Screen adaptation

- Material3-style window tiers (Compact / Medium / Expanded / Wide) on top of the
  existing rail logic. Tracks now flow into **three columns** on large windows,
  long text columns cap at 720 dp, page gutters scale 16 → 32 dp, and short
  landscape windows get a smaller bottom pad so the chrome no longer crowds the
  content.

## Dark & light

- Elevation alpha is split per theme, ink adapts automatically over artwork, and
  the static glass base stays role-aware (sheets denser than pills).

## Validation

This version was committed as a design-system change **without an APK**. Compilation
was not run where it was authored (no JDK / Android SDK in that environment). The
changes are additive with defaults and were reviewed statically, but a Gradle build
and on-device check remain required before any store/publication step.

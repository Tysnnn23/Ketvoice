# Ketvoice 3.13.9

![Ketvoice](https://raw.githubusercontent.com/Tysnnn23/Ketvoice/main/ketvoice-banner.png)

## Artist pages, Apple Music-inspired

- **HD artwork** is resolved by MusicBrainz identity through Fanart.tv:
  `artistthumb` portraits, `artistbackground` and `musicbanner`, validated on the
  server and cached for 12 hours. The app uses the portrait when available and a
  background as ambience, with a 220 ms crossfade and no blank flash.
- The hero fades into the page with a long gradient and keeps the name, the
  signature and the actions readable; square portraits fill the frame instead of
  being cropped to a random band.
- **Authentic signatures** are looked up through Wikidata `P109` (resolved from the
  exact MusicBrainz `wikidata` relation) and rendered from Wikimedia Commons. If
  none exists, a transparent Fanart logo is used. If neither is reliable, the
  premium typographic name is kept — no invented signature.
- New settings: **Photos d'artiste HD** (on by default, public artwork only) and
  **Signatures et logos d'artistes** (still opt-in, because the artist name is sent
  to the broker).
- Verified live: Eminem and Juice WRLD return HD portraits; Juice WRLD returns his
  Wikidata signature. Artists without provider artwork keep the YouTube photo.

## Lyric glow, rebuilt

- Activation is now adaptive at **1.05 s**: rap syllables and ordinary words never
  glow, held notes do. The glow follows the note's real timestamps (pause, seek and
  speed included), never a timer.
- Appearance: diffuse low-alpha white halo plus a subtle inner light, with a
  left-to-right luminous sweep and a light organic drift. No contour, no neon
  outline, no opaque halo.
- Held notes grow smoothly to **1.07×** around their own centre, then settle back.
  Only held notes pay for the extra draws; everything else stays a single fill draw.

## Discord

- The OAuth2 redirect is now the HTTPS bridge page
  `https://ketvoice.netlify.app/discord.html`. Register **that** URL in the Discord
  Developer Portal: it forwards the code to `ketvoice://discord` (and the in-app
  WebView now also completes directly on the HTTPS URL). This removes the custom
  scheme requirement that the portal was missing.
- Presence still opens the Discord app and connects; the SDK log line is shown when
  it fails. Note that launching Discord alone does not create a presence: the
  session must reach Ready, which the OAuth link makes reliable.

## Validation

- Unit tests, release builds, lint and the credential scan run before publication.
  No phone or emulator is available here: the artist crop, the glow feel, the OAuth
  return and the presence are **not hardware-validated**. The artwork broker was
  verified live against Eminem and Juice WRLD.

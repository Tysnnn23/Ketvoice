# Ketvoice 3.14.0

![Ketvoice](https://raw.githubusercontent.com/Tysnnn23/Ketvoice/main/ketvoice-banner.png)

## Lyrics

- The held-note glow now starts at **870 ms** instead of 1.05 s, so more sustained
  words and syllables bloom while fast rap stays clean. Everything else — diffuse
  halo, inner light, 1.07× growth, luminous sweep, audio clock — is unchanged.

## App interface

- **Playlist** header (cover, name, play/shuffle) no longer scrolls away: only the
  track list moves, so the artwork stays in place.
- The floating navigation bar now condenses after **24 px** of scroll on Home,
  Explorer and Library instead of waiting for the second item.
- **Custom sources** can be reordered by dragging the three-line handle. The list
  order is the priority order and is saved on the device; each card shows its
  priority.
- Discord: **Lier mon compte Discord** is now directly visible in the panel and
  opens the in-app WebView OAuth flow, instead of being buried in the advanced
  section.

## Ketvoice Studio

- Complete dashboard layout: fixed sidebar with the owner account, section
  navigation and service status; sticky top bar; pink-on-black accent theme;
  responsive down to a phone.
- **Sources API** cards are draggable (three-line handle). The new order is saved
  as `sort_order` in Supabase and restored on any computer.
- **Se souvenir de ce PC** keeps the owner session in local storage and restores it
  on the next visit; logging out clears it.
- Albums, per-track Canvas, metadata, covers and lyrics keep their existing
  endpoints and behaviour.

## Validation

- Unit tests, release builds, lint and the credential scan run before publication.
  The Studio was opened locally (layout, pink theme, session checkbox, no console
  errors) but the authenticated drag order and the mobile screens were **not
  device-validated** here.

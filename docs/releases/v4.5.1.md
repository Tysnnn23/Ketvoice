# Ketvoice 4.5.1

![Ketvoice](https://raw.githubusercontent.com/Tysnnn23/Ketvoice/main/ketvoice-banner.png)

## Previous navigation and player presentation restored

- Restore the pre-4.5 floating navigation: the mini-player, tab capsule and search
  button have their own surfaces again, in both expanded and compact states.
- Restore the cover-first phone player. The track title and favorite/options
  controls return below the artwork instead of the added top identity header.
- Remove the added Pochette/Paroles/File d'attente selector from phone, tablet and
  Quest player headers. The previous bottom controls and page access remain.
- The four navigation/player layout components match their 4.4.0 versions. Canvas
  focus, dismissal gestures and the existing landscape 2D Quest layout remain.

## Clean lyrics and the rest of 4.5.0 are kept

This is not a rollback of the lyric renderer: synchronized white progression,
foreign-script alignment and backing vocals remain, without enlarged or diffused
word copies. The lyric-rendering files are unchanged from 4.5.0.

Persistent playlist pins, local album grouping, library views, multiple selection,
offline filters, confirmed batch deletion and the personal Home remain. General
glass-material improvements are not reverted. The accessible queue drag target is
also retained.

## Validation scope

Host checks verify the restored navigation in both states, title placement below
the phone artwork, absence of the added player tabs and the unchanged clean-lyric
pixel regression. Mobile/Quest JVM suites, release lint and APK verification are
recorded in `validation.json`. Instrumentation compilation is not execution.

Software previews are not physical device screenshots. Phone/Quest installation,
real GPU blur/refraction, controller/touch feel, measured FPS, live providers and
DAC behaviour still require device validation. French and eleven interface
languages, Canvas and karaoke are retained. No group-listening feature or
publisher authorization change is included.

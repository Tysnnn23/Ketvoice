# Ketvoice 3.17.1

![Ketvoice](https://raw.githubusercontent.com/Tysnnn23/Ketvoice/main/ketvoice-banner.png)

- The new collection header (liked songs, recently played, all tracks) now **scrolls with the list** instead of staying pinned above it, exactly like the playlist and album pages. The title bar keeps only the back action, so small screens recover the space.
- Everything else is unchanged from 3.17.0: edge-free artist hero with real refresh and share, playlist/album share links, playlist-style collections and downloads, persisted Discord PKCE state with a direct token exchange, progressive playback fallback and two-track prefetch.

Validation: the full suite (299 debug / 254 release tests per variant), lint with zero errors, credential scan with zero findings, signed Mobile and Quest APKs, and public download hashes verified after publication. The Discord token endpoint was exercised live with an invalid code (`HTTP 400 invalid_grant`), which validates the client id, redirect and request shape without logging in an account. Real consent with your Discord account and physical-device playback remain untested here.

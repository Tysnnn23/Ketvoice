# Ketvoice 3.13.0

![Ketvoice](https://raw.githubusercontent.com/Tysnnn23/Ketvoice/main/ketvoice-banner.png)

## Discord account linking

- Link a real Discord account from the account panel using the official Discord
  Social SDK and the registered Ketvoice application
  (`1566454532890820668`). The OAuth2 redirect
  `discord-1566454532890820668:/authorize/callback` returns the authorization
  code straight to Ketvoice.
- Authorization uses PKCE with an SDK-generated state value. Ketvoice never asks
  for a Discord password, never stores a user token and never approximates a
  "linked" badge.
- The seven-day access token is renewed from the non-expiring refresh token, which
  is kept encrypted by an Android Keystore AES-GCM key and can be deleted at any
  time with **Unlink my Discord account**.

## Live listening presence

- Once linked and enabled, Discord shows the track title, the artist, the cover
  when it is a public HTTPS image, and an elapsed-time counter aligned with the
  current playback position.
- Two buttons: **Download ketvoice** → `https://ketvoice.netlify.app/` and
  **Listen now** → the track's public listen page. Expiring media URLs and local
  file paths are never published.
- Presence is opt-in, appears only while a track is actually playing, and is
  cleared on pause, stop, unlink or opt-out.

## Packaging and limits

- The Discord Social SDK is owner-supplied and is **not** redistributed through
  Git. Builds without `app/libs/discord/discord_partner_sdk.aar` still compile and
  simply hide the Discord panel; the published APK includes the arm64 runtime.
- The SDK adds about 9 MB of native libraries to the phone APK. Voice chat,
  microphone permissions and the SDK's foreground service are not included.
- **Not validated on hardware.** No phone, Quest or accelerated emulator was
  available here, so the real OAuth redirect, the Discord-side presence and both
  buttons were not observed. Discord also does not display your own buttons to
  you, so confirmation needs a second account.
- Canvas, reverb and the rest of 3.12.1 are unchanged.

# Ketvoice 2.7.1 — Quest landscape player

**Quest-only update · versionCode 16 · 22 October 2026**

Download **`Ketvoice-2.7.1-Quest.apk`** for Quest 3/3S. The published **mobile/tablet 2.7.0 APK is unchanged**; there is no new phone APK in this release.

## Landscape, properly arranged

- Main app and YouTube login request **landscape only**. The default Quest panel is **1280 × 800 dp**, with a requested minimum of **960 × 600 dp** and aspect-ratio lock metadata for Horizon OS.
- Removed the portrait-phone frame and its wide-window black sidebars. The player uses the landscape window.
- **Lyrics mode:** artwork/animated Canvas, title, artist, seek bar, transport, and volume remain **left**; real synchronized lyrics, source selection, and translation remain **right**.
- **Queue mode:** the queue replaces only the right-hand pane, retaining the artwork and controls on the left.
- **Artwork mode:** large artwork left, normal playback controls right.
- The two-second phone lyric auto-expansion no longer hides the left column on Quest. The phone behavior is unchanged.
- Reuses the mobile player's original icons, transport controls, volume, typography, artwork/Canvas, karaoke, and existing settings. No giant text-button toolbar or new dashboard. Artwork resizing and pane changes are animated; reduced-motion preferences are respected by the new transitions.

## Install

Use Meta Quest Developer Hub, SideQuest, or:

```text
adb install -r Ketvoice-2.7.1-Quest.apk
```

The existing development signing certificate and package name are retained, allowing an update over Quest 2.7.0 without uninstalling. See the [Quest guide](https://github.com/Tysnnn23/Ketvoice/blob/main/docs/QUEST.md).

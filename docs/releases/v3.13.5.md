# Ketvoice 3.13.5

![Ketvoice](https://raw.githubusercontent.com/Tysnnn23/Ketvoice/main/ketvoice-banner.png)

## Lyrics

- The glow is back to a word-level effect: only sustained notes bloom, reinforced
  by a thin contour on the sung glyphs. Ordinary lyric lines no longer carry a
  permanent halo.
- Backing vocals now derive their window from the parent line when the provider
  gives no word timings, so a back stays visible for its real duration instead of
  flashing for a few hundred milliseconds. The row still appears only 200 ms before
  the back and collapses after it, and a long back can finish after the next line.
- The translated line is revealed with an eased sweep and a per-glyph opacity ramp
  at the boundary, removing the visible step-by-step jumps.

## Fullscreen Canvas

- The title, artist and duration/scrub row are **always visible** in fullscreen.
- Tapping the artwork returns to the normal player; the scrub bar keeps its own
  gestures and never triggers the exit.

## Higher-quality audio

- When the requested quality is Lossless or High, Ketvoice now prefers YouTube's
  best adaptive audio over the broker's 128 kb/s MP3, and labels the real codec and
  bitrate. Downloads try YouTube after lossless and before the broker MP3.
- The third-party lossless provider is still expired, so true FLAC is not restored.
  The app no longer presents 128 kb/s as high quality without saying so.

## Discord

- The presence mode is unchanged: it uses the installed Discord app and now offers
  an **Open the Discord app** shortcut so the prerequisite is explicit. Account
  linking remains optional. This path is still **not device-validated** here and
  the exact failure message matters for the next step.

## Validation

- Unit tests, release builds and lint run for both variants. No phone, Quest or
  accelerated emulator was available, so the lyric timing, fullscreen gestures and
  audio quality are not hardware-validated.

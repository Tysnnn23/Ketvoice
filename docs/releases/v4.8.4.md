# Ketvoice 4.8.4

![Ketvoice](https://raw.githubusercontent.com/Tysnnn23/Ketvoice/main/ketvoice-banner.png)

## Collapsed chrome on 320–379 dp phones

- The collapse animation was gated on a 380 dp minimum width. Many phones report a
  360 dp logical width, so the chrome never moved. The threshold is now 320 dp, which
  is the minimum supported window and the width at which the three glass elements
  still fit (52 + 8 + mini-player + 8 + 52 + 24 dp).
- At 320 dp the row is: Home (52 dp glass circle), a smaller mini-player with a 32 dp
  cover and 48 dp Play/Next targets, and Search (52 dp glass circle). The three tabs
  are replaced by the Home button while scrolled.
- Scrolling back up still restores the full mini-player above the three-tab capsule.
- The host regression test now renders the collapsed row at 320 dp and asserts
  Home → mini-player → Search ordering, no overlap, a 48 dp transport target and the
  absence of the Explorer/Library tabs.

## Retained

- The 4.8.3 Home / mini-player / Search morph at wider widths.
- Discord presence through the installed app over RPC (4.8.2).
- Device language on first launch and the System language entry (4.8.1).
- All 4.8.0 playback, search, backup, lyric, Home and restricted offline DASH behaviour.

## Validation limits

No phone or Quest was connected for this build. The 320 dp and 400 dp Robolectric
host tests prove the geometry and semantics, not the on-device liquid-glass
refraction, spring feel or GPU frame rate. JVM tests, lint, signatures and checksums
are not device validation.

For update compatibility these APKs use the existing public Android debug signing identity, not a private production signing key. Never uninstall an existing installation to resolve a signature conflict without backing up its data.

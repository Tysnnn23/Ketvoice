# Ketvoice 3.0.4 — desktop studio and managed sources

**Mobile/tablet and Quest · versionCode 29**

- Open `admin/ketvoice-admin.html` directly in a modern desktop browser. Sign
  in with the verified owner e-mail link or OTP to publish audio and artwork,
  change metadata/audio/cover on your own imported tracks, and upload lyrics.
- Add, edit, disable or delete compatible HTTPS `manifest.json` sources. The
  Ketvoice API discovers active sources for each search or stream request, so
  existing mobile/Quest installations receive content changes automatically
  without notifying listeners. Signed URLs must be replaced when they expire.
- On artist pages, short banners extend into a softly blurred image backdrop
  rather than ending above a flat empty area.

The HTML cannot silently replace an installed APK. Edits to third-party
catalogue tracks remain prohibited. Owner e-mail delivery/login and physical
phone/Quest visuals require verification by the owner; they are not covered by
automated tests.

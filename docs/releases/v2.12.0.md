# Ketvoice 2.12.0 — playlists, Spotify import & selected design finishes

**Mobile/tablet and Quest — versionCode 21**

## Playlists on your device

Library → **Playlists** now offers **Créer une playlist** and **Importer depuis Spotify** side by side.

- Create, rename and delete a playlist. Deletion removes only the playlist; songs and downloads stay.
- Add a song from its menu → **Ajouter à une playlist**. A new playlist created from that sheet already contains the song.
- Reorder with **Monter** / **Descendre**, remove a title, then play the whole list or a single row.
- Playlists are stored locally in an atomic JSON file (bounded to 100 lists and 500 entries each). Nothing is uploaded, and a corrupt file is reported instead of being silently replaced.
- Stored entries keep the song identity, not expiring stream URLs. If a list was imported from Spotify, titles that were not found remain visible and can be resolved by hand.

## Spotify import

Paste a **public** Spotify playlist link (`open.spotify.com/playlist/…` or `spotify:playlist:…`), load the public preview, then match the visible titles against the Ketvoice catalog.

- Ketvoice reads the same public preview page a browser sees; it does not sign in to Spotify, does not use Spotify cookies and never downloads Spotify audio or its 30-second previews.
- Spotify does not guarantee that this public preview lists every track. Ketvoice displays the number of visible titles, states that the list may be incomplete, and requires an explicit confirmation before creating the playlist.
- Each title is matched on normalized title, main artist, official-catalog verification and duration tolerance. Results show **Disponible** or **Non retrouvé**; unresolved titles are never presented as playable.
- The import cover is an original Ketvoice composition tinted by the playlist colour, optionally using the public artwork URL as a dimmed background. It is not an official Spotify logo.

## Selected design finishes (D1–D8)

Every retained finish has its own switch in **Réglages → Design Ketvoice**, so a single element can be reverted without losing playlists, downloads or settings.

- **D1 Signature Ketvoice** — compact wordmark header, deeper night background, calmer card surfaces.
- **D2 Accueil éditorial** — one featured card (“À l'affiche”) above the shelves; the featured title is not repeated in its shelf.
- **D3 Cartes de collections** — collection cards show a 2×2 artwork mosaic and a real category icon.
- **D4 Typographie harmonisée** — heavier weights pull back to ExtraBold and unset line heights get a 1.30 reading ratio.
- **D5 Menus unifiés** — dialogs share one readable surface, corner radius and hairline border.
- **D7 Éditeur visuel des imports** — the publisher sees current vs replacement artwork, filename, format, size and duration before submitting.
- **D8 Finitions Quest** — tighter control spacing, a vertical divider and a framed panel on the lyrics/queue side, still a 2D landscape window.

D6 was not implemented.

## Whole-app translation

- French remains the source language and the default; the same 11 interface languages are offered.
- A new audit extracts public labels and message templates from the UI sources. The bundled catalog now holds **745 messages per language** across the 10 non-French languages, with placeholder parity verified for every entry.
- Brand names (Ketvoice, Spotify, YouTube Music, LRCLIB, LRC, TTML, FLAC, MP3) stay untranslated. User content (titles, artists, lyrics, playlist names) is never translated.
- The chosen language is also applied to native Android surfaces (file picker, permission and system dialogs), not just Compose text.

## Validation

- **117 JVM tests** per flavor (mobile and Quest), zero failures, including playlist rules, Spotify link/preview parsing, unmatched-title handling, and translation parity.
- **15 Android Compose tests** run on an Android 15 emulator (12 existing + 3 playlist/import checks).
- Same Quest landscape viewport checks as 2.11.0: 1280 × 800 dp, control and lyrics/queue sides preserved.
- Lint and release build results are published with `validation.json`; APK checksums are listed in `SHA256SUMS.txt`.
- No real Spotify account, no real Spotify audio download, no authenticated owner edit and no physical Quest 3/3S run is claimed. Spotify previews are public and may be incomplete or region-dependent.

## Ketogether is still deferred

Group listening has not been added. The existing single-device Wi-Fi handoff is unchanged and does not create a shared session.

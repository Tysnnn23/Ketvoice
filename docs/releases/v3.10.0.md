# Ketvoice 3.10.0 — Canvas framing fix and simpler playback

**versionCode 54** — signed Mobile and Quest packages, using the existing update certificate.

## Normal Canvas framing fixed

The regular player no longer applies the artwork fade mask or dark lower
overlay to Canvas video. Clips have their own unobscured viewport between the
header and track information, stay centered with their full proportions, and
do not run underneath the title. Static artwork keeps its existing dissolve.
The compatible-clip fullscreen mode remains available.

## AutoMix completely removed

The dual-deck engine, beat analysis, transition commands, background preparation,
overlay and settings have been removed. Playback uses one audio player again.
Upgrades remove the retired settings and analysis cache without deleting songs,
artwork or playlists. Equalizer, Sonic Canvas, shuffle, repeat, seeking,
skip-silence, downloads and single-device Wi-Fi handoff remain.

## Website and release presentation synchronized

The website removes the retired feature from its current descriptions, shows
the canonical Ketvoice banner, and refreshes stable release notes and Mobile /
Quest downloads from GitHub. New changelogs and release notes are in English.
Historical releases and their assets remain unchanged.

## Install

Download the Mobile APK for Android phones/tablets or the Quest APK for the
landscape 2D Quest window. Both update existing installations without clearing
the library. Checksums and validation metadata accompany the APKs.

## Validation and limitations

Exact JVM, host Android/Skia, lint, APK signature, alignment and credential-scan
results are recorded in `validation.json`. Public release downloads are
compared with local SHA-256 values. The Canvas regression uses a synthetic
frame to verify that bottom pixels stay visible; it does not validate a real
video decoder or hardware GPU. Website checks distinguish local browser tests
from any live deployment verification.

No phone, emulator or physical Quest is used. Final APK installation/launch,
real Canvas playback, owner-session and in-app live downloads are not claimed.
No backend authorization, Apple sources or group listening is changed. The
parallel local `MainActivity.kt` work is preserved outside this release.

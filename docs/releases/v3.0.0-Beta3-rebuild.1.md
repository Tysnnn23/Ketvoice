# Ketvoice 3.0.0-Beta3 — rebuilt APKs

**App version: 3.0.0-Beta3 · versionCode 25 · release tag: v3.0.0-Beta3-rebuild.1**

## Why a rebuild?

The originally published mobile Beta3 APK downloads with the advertised SHA-256
(`e5e8db6981d84fd1f8323d4af388946cbc72e66b1368af4c6d68a6e30eb125bc`) and
passes ZIP CRC checks, but **does not pass Android signature verification**:
`apksigner verify` reports `Missing META-INF/MANIFEST.MF`. An intact ZIP is not
necessarily an installable APK. This rebuild fixes the packaging, not merely
the download link. The original release/tag/assets remain untouched.

## Changes retained and fixes

- Rebuilt from the recent Beta3 sources, including the artist banner, local
  music page, glass back buttons, tablet swipe-to-close, image-cache purge and
  drag feedback on the seek bar. This is not a recompile of 2.12.0.
- `assembleMobileRelease` / `assembleQuestRelease` now sign their outputs using
  the existing external Android Debug development keystore, or an explicitly
  configured external signing identity. No key or password is added to Git.
- The release gate rejects unsigned, truncated, misaligned, debuggable,
  wrong-version and wrong-certificate APKs. It checks ZIP CRC, `apksigner`,
  16 KB ZIP alignment, manifest version/SDKs and SHA-256, then verifies uploaded
  bytes by downloading them before publication.
- Captured main-screen content cannot sample its own backdrop anymore. Sibling
  chrome still uses Liquid Glass. This hardens Beta3's existing back-button fix
  against further RenderThread render-recursion crashes.
- Artist/catalog optional artwork errors do not crash/hide a usable page;
  cancellation is rethrown instead of swallowed, and catalog loading failures
  reach the existing retry state.
- Local music now asks for audio permission on Android 13+ and legacy storage
  permission on Android 12/12L. A denied permission is explained, not reported as
  an empty library. Returning from app settings rescans with current permission.
- Local file read failures have a retry state, the final rows clear the floating
  navigation, and the local/catalog covers are actual 2×2 mosaics rather than four
  vertical strips. New permission messages are bundled in all 11 UI languages.

## Installation

- **Phones/tablets:** `Ketvoice-3.0.0-Beta3-rebuild.1.apk` (Android 12+, target 36).
- **Quest:** `Ketvoice-3.0.0-Beta3-rebuild.1-Quest.apk` (minimum SDK 32, target 34).
- Keep your installed app/data: install the new APK as an update. The package
  name and existing development certificate are preserved, and versionCode is
  increased from 24 to 25. Do not uninstall merely to work around a failed
  download. Copies signed by a different key cannot be updated with this key.
- This remains a development-signed **prerelease**, not a Play/Meta Store build.

## Validation and limits

- 117 JVM tests and 19 Android Compose tests pass **per flavor**, with no
  failures/errors/skips. The new rendered tests exercise capture isolation,
  repeated artist/settings/catalog/local screens and denied audio permission.
- Eight Python release-gate tests pass (SDK commands mocked in those unit tests).
- Release lint: 0 errors, 142 warnings and 8 hints per flavor; warnings are not
  advertised as fixed bugs.
- Both actual release APKs pass ZIP CRC, signature/certificate, manifest and
  16 KB ZIP-alignment checks. Both install as updates and launch on an Android 15
  emulator with no app crash in the inspected crash log. The mobile release's
  audio permission request/accept/rescan flow was also exercised.
- Credential scan: 1,175 source/archive entries, 0 findings (pattern scan; no
  claim of a new audit of server secrets).

See the accompanying `validation.json` and `SHA256SUMS.txt` for exact results,
certificate, source commit and file hashes. Tests cover the existing playlist,
player, translation and Quest checks, hardware-rendered glass captures, repeated
overlay rendering and missing local-audio permission. Release APK installation
and launch checks are separate from debug instrumentation tests.

No claim is made that every possible bug is eliminated. No owner-session upload,
full live Spotify/provider playback/download, Android 12 physical device or
physical Quest 3/3S test is claimed. The attached phone is not used for testing.
No backend schema/auth change or Ketogether feature is included.

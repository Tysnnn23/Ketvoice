# Ketvoice 3.8.0 — verre ciblé et nouveaux réglages

- Adaptation des primitives optiques de **PrismalAGSL**, sous licence MIT :
  profil de lentille, réfraction du fond réel et reflets directionnels sur les
  contrôles et la navigation. Attribution embarquée dans l'APK.
- Le verre n'est plus appliqué aux grandes cartes et feuilles de contenu :
  les panneaux restent mats, les contrôles portent les effets.
- Paramètres réorganisés : accueil par catégories, pages dédiées, groupes
  plus lisibles et interrupteurs accessibles sur toute leur ligne. Les options
  existantes, y compris publication, sources, AutoMix et musique locale, restent
  reliées à leurs actions réelles. Les finitions avancées ont leur propre page.
- Barre de recherche compacte, champ et texte indicatif sur une ligne,
  largeur bornée sur grand écran, bouton d'effacement et action clavier
  conservée. Les segments de recherche et libellés de navigation ne se replient
  plus sur deux lignes.
- Chrome condensé allégé pour éviter le chevauchement des contrôles sur petit
  écran. Mouvements réduits respectés pour la lentille et l'appui.
- Les 11 langues et le français par défaut sont conservés ; les nouveaux
  intitulés des catégories sont traduits.

## Validation

Les résultats exacts JVM, tests hôtes Android/Skia, lint, signature,
alignement, scan de credentials et SHA-256 sont joints dans `validation.json`.
Les téléchargements de release sont comparés aux fichiers locaux.

Les prévisualisations et tests hôtes sont **des simulations sur PC**, sans
AVD ni téléphone. Ils ne constituent pas un test de performance GPU réel.
Aucun parcours exhaustif, installation/lancement de l'APK final, test de
session propriétaire, téléchargement dans l'app ou casque Quest physique
n'est revendiqué pour cette livraison. Les tests instrumentés sont compilés
mais non exécutés sur appareil.

Le verre AGSL complet nécessite API 33+. Android 12/12L et les modes allégés
utilisent le repli prévu ; la fenêtre Quest reste 2D et paysage. Aucun travail
Apple ni écoute de groupe n'est ajouté. Le changement parallèle local de
`MainActivity.kt` est préservé hors de cette livraison.

Référence et détails : [docs/PRISMAL-GLASS.md](../PRISMAL-GLASS.md).

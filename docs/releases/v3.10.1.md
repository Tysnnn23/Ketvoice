# Ketvoice 3.10.1 — reliable in-app update checks

**versionCode 55** — signed Mobile and Quest packages with the existing update certificate.

## Automatic checks restored

Update checks now run when the app returns to the foreground and every fifteen
minutes while it remains active. An available release is persisted, so closing
and reopening the app during the check interval no longer loses the update.
Failed requests do not suppress retries. A freshly installed app version always
checks again. Stable builds select the newest installable stable release and
keep Mobile and Quest packages separate.

## Manual checks and installer retry

Settings → About now includes Check for updates, with visible checking,
up-to-date and failure feedback. Manual checks can reopen a skipped version.
The update badge no longer cancels its own asynchronous request.

After granting Android's install-apps permission, the verified APK is reused to
continue installation. Launching or cancelling the system installer no longer
leaves the button permanently at 100%. The dialog keeps a retry action and a
GitHub fallback. Android still requires the owner's installation confirmation;
this is not silent installation and does not bypass platform permissions.

## Verified update packages

Downloads follow HTTPS-only GitHub asset redirects, require the exact release
size, and check GitHub's SHA-256 digest when supplied. Partial or rejected
downloads are never handed to the installer. The APK must have the installed
package name and signing certificate, a higher versionCode, the advertised
versionName and a supported Android minimum version. Cached APKs are checked
again before installation. Six new interface messages are translated into all
ten non-French dictionaries; French remains the default.

## Install

Install the Mobile APK on a phone/tablet or the Quest APK in the landscape 2D
window. If an older build's updater cannot discover this fix, download this
version once from GitHub; subsequent checks use the corrected updater.
Checksums and validation metadata accompany both signed APKs.

## Validation and limitations

The release metadata records JVM, host Android/Skia, mocked transfer/installer
checks, lint, signature, alignment and credential-scan results. Public release
downloads are compared with local SHA-256 hashes. Host tests cover selection,
cache/relaunch, clock changes, retry, digest/size rejection, partial-file cleanup
and reusable installer UI; they are not actual package-manager installations.

No phone, emulator or physical Quest is used. Real install-permission return,
upgrade installation, owner-session and in-app live download validation remain
not performed. The website's English notes/download feed is synchronized;
production-host deployment is distinguished from local browser verification.
AutoMix remains removed; no backend, Apple or group-listening work is added.
Parallel local `MainActivity.kt` work remains outside this release.

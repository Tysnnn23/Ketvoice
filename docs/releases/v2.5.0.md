# Ketvoice 2.5.0

**Android 12+ · versionCode 12 · 21 October 2026**

## What's new

- **11 interface languages:** French (default), English, Hindi, Japanese, Chinese, Russian, Italian, Spanish, German, Portuguese, and Korean. Translations ship offline; songs, artists, and original lyrics remain unchanged.
- **Working offline downloads:** chosen-quality preference, HTTPS redirects, retry/resume, audio validation, and playable fallbacks. Local files now bypass the HTTP streaming data source.
- **Lyrics with your music:** best available native syllable/word/line timing or plain text, saved as JSON and LRC sidecars. Local lyrics load before network providers.
- **Canvas with downloads:** available video stays in persistent shared storage, with track-ID and artist-qualified album reuse.
- **A new Library:** local music card, collection cards, artist circles, albums, recent plays, and downloads, driven by actual listening data.
- **Player motion:** fading cover flight between the full player and mini-player, animated lyric emphasis and lyric-view transitions, and a larger sequential three-dot intro that grows, merges, and disappears.
- **Provider cleanup:** built-in routing now uses only Ultra MAX and Last Babe. The retired provider route and Vault secret were removed from the deployed backend.
- Includes the **Ketvoice API / Supabase credential isolation** originally prepared for the unpublished 2.4.0 candidate. No Spotify session or private add-on token is bundled.

## Limitations

Third-party services may rate-limit requests or lack the selected audio quality, lyrics, or Canvas. A download may fall back to a lower audio quality; the app reports the format actually saved. Explicit song downloads can fetch Canvas over mobile data. Interface translations are machine-assisted with curated corrections. No physical-device validation is available.

Only the final new APK is attached. The unpublished 2.4.0 build and historical credential-bearing APKs remain withheld.

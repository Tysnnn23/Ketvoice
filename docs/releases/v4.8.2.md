# Ketvoice 4.8.2

![Ketvoice](https://raw.githubusercontent.com/Tysnnn23/Ketvoice/main/ketvoice-banner.png)

## Discord presence without account linking

- Discord Rich Presence on Android is now published through the **installed Discord app over RPC**, which is the path Discord documents for presence without authentication (Android, Social SDK 1.10+). It needs neither an OAuth token nor a `Ready` gateway connection.
- The Discord panel now offers **Afficher via l'app Discord** as the primary action. Ketvoice creates a bare SDK client that only knows the application ID and sends the activity whenever a track plays. The Discord app must be installed, open and signed in.
- Each presence update reports its result: success clears the error, and a refusal shows the SDK message under the action.
- Account linking remains available under **Lier mon compte Discord (avancé)** for account features, but it is no longer required for the listening status. The previous gateway loop was bounded, and it no longer restarts every time the app returns to the foreground.
- The Discord activity keeps the **Listening** type and its status line now shows the track title instead of only the application name.
- Diagnostics report the mode (`app-discord-rpc` or `compte`), whether the last presence update succeeded and its error, plus the last SDK log line.

## Language and previous work

- The 4.8.1 device-language behaviour is retained: Ketvoice starts in the phone language when supported, offers an explicit **System language** entry and clears a previously pinned per-app locale.
- All 4.8.0 playback, search, backup, lyric, Home and restricted offline DASH behaviour is retained.

## Validation limits

No phone or Quest was connected for this build. JVM/Robolectric tests, lint, signatures and checksums do **not** prove that the installed Discord app accepts the RPC presence, that Discord renders it on another client, or that the language switch is visible on a physical device. The panel now returns the exact SDK result, so a refusal is diagnosable instead of silent. Discord never shows your own presence buttons to you; verify from another account or device.

For update compatibility these APKs use the existing public Android debug signing identity, not a private production signing key. Never uninstall an existing installation to resolve a signature conflict without backing up its data.

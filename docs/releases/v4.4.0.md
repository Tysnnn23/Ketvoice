# Ketvoice 4.4.0

![Ketvoice](https://raw.githubusercontent.com/Tysnnn23/Ketvoice/main/ketvoice-banner.png)

## Glass with a quieter centre

- Clear controls retain more of their real backdrop: less blur, restrained
  saturation, a narrow refracting edge and a finer directional rim. The broad
  diagonal streak and corner halo are removed. The shader no longer stacks its
  colour treatment on top of a second vibrancy pass.
- Expanded and compact navigation use the same moving-selection material instead
  of separate, strongly distorting lenses. Pressing a glass button compresses it
  slightly rather than enlarging it. Navigation colour fades now respect reduced
  motion as well as the positional transitions.
- Clear, Frosted and Opaque remain available. Matte content panels stay matte;
  readable static fallbacks remain for unsupported or disabled optical rendering.
  Static controls now clip their contents to their actual shape.

## Downloads rebuilt around what is really on disk

- A compact offline-library summary replaces the large collection-artwork collage.
  Playback and shuffle are offered only when saved files exist.
- Transfers and saved tracks have separate sections. A transfer is never treated
  as a playable offline file, and completed/cancelled entries do not linger in the
  transfer section. Failed entries can be retried or dismissed.
- Local search filters by title, artist or album without altering the stored files.
  Offline playback from the filtered list uses that list's order.
- Each transfer shows its state once. Byte progress is determinate only when a
  total is known; unknown-length transfers do not invent a percentage. Restored
  pauses expose Resume even when they have no active worker.
- Deleting a saved file now requires confirmation. Cancel keeps the file locally:
  there is no misleading Undo action that silently starts another download.
- Saved rows show actual format and file size, saved lyrics/Canvas availability,
  and a 48 dp delete target. The list scrolls independently of the back header.

## Albums rebuilt as a reading and listening surface

- Phone artwork remains edge-to-edge, starting at the window top, without a square
  cover card. A shorter hero brings the identity and playback actions closer to the
  first screen. The image fades only near its lower edge into the actual page.
- Title, artist, year, track count and total duration form a left-aligned identity
  block. On wide windows the artwork and identity sit beside one another; both
  scroll away normally instead of leaving a pinned blank area.
- Large fonts on narrow windows stack the playback actions instead of breaking
  their labels. Reduced motion removes list movement and artwork parallax.
- Numbered track rows no longer repeat the same album thumbnail. Current-track
  emphasis, saved-file indicators, durations, track options and swipe queue actions
  remain available. Back and share remain floating glass controls.
- Album Canvas keeps its independent setting and its reduced-motion/performance
  fallback. Player Canvas, karaoke, optional Stats info and the landscape 2D Quest
  player layout are not replaced by this redesign.

## Validation scope

Unit and native-software host tests cover section separation, local filtering,
failed-transfer dismissal, confirmation cancellation with the file preserved,
restored pauses, empty libraries, large-font/narrow and short-landscape albums,
and shader edge displacement without centre warping. The image preview uses a
decoded local fixture injected into the image loader, not a live provider.

Software previews are not device screenshots. Real GPU blur/refraction, physical
phone/Quest installation, controller feel, measured FPS, DAC behaviour and live
provider/download/Discord sessions require device validation. No new evidence for
those checks is implied by a passing host suite or by compiled instrumentation.

French remains the default; four new labels are supplied in all ten other
interface languages. No group-listening feature or publisher authorization change
is included. Existing released tags and assets remain intact.

# Ketvoice 2.10.0 — album colours, artwork depth & library motion

**Mobile/tablet and Quest · versionCode 19**

- **D2:** Player accents sampled from the album artwork, adjusted for contrast against a dark reference surface. Disable **Couleurs de la pochette** to keep your chosen accent. Other app screens keep their existing accent.
- **A1:** Subtle artwork depth follows touch/pointer movement without consuming normal gestures. Disable it in Settings; reduced motion also disables it.
- **A2 / A4:** Library collections enter once per screen state; album cards animate to their new positions when sorted by recent order, title or artist. Sorting does not alter playback order.
- **A3:** Track artwork shows actual download progress and a brief confirmation after an observed job saves its audio. Active downloads appear before completion; optional sidecar finalization has its own label.
- **V2 / V3 / V5:** Longer titles wrap or scroll only when selected; empty screens offer working search/retry actions; Quest secondary text and contrast are clearer, without changing its mobile-style controls or landscape split panes.
- **A5 remains deferred by user choice.** No pretend playlist-add action or editable-playlist feature has been added.

The existing 2.9.0 artist banners and clickable artist names remain. Equalizer, same-Wi-Fi handoff, Canvas and the fixed-size introductory lyric dots are retained. No backend or publisher-authorization change is made.

## Downloads

- `Ketvoice-2.10.0.apk`: Android 12+ phones/tablets, target SDK 36.
- `Ketvoice-2.10.0-Quest.apk`: Quest 3/3S 2D landscape window, minimum SDK 32, target SDK 34, arm64-v8a and x86_64.

Both use the existing Android Debug development certificate, allowing an update without uninstalling. This is not a Play Store or Meta Store signing identity.

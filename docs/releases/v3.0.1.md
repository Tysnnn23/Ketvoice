# Ketvoice 3.0.1 — immersive artist profiles

**Mobile/tablet and Quest · versionCode 26**

## Artist pages

- Artist profiles now lead with a large, unblurred portrait and a gradual
  transition into a color sampled from the image.
- The artist name, listener information, source and play action are integrated
  into the artwork header. The biography and catalog sections remain below it.
- Biographies are translated to the app's selected interface language. The
  source description remains visible if translation is unavailable.

## Player navigation

- Tapping an available artist name in the full-screen player opens that artist's
  profile and collapses the player into the mini-player without stopping audio.

## Build validation and limits

- Mobile and Quest release APKs build successfully and pass ZIP CRC, signature,
  signing-certificate, version/SDK and 16 KB alignment checks.
- 117 JVM tests pass per flavor, with no failures, errors or skipped tests.
- Release lint reports no errors. Existing warnings are retained and not claimed
  as fixed.
- Android Compose instrumentation and release install/launch tests were not run
  in this session. No physical phone or Quest is claimed as tested.
- At the user's request, publication proceeds with this explicit validation
  limitation. Please install and verify the mobile APK before relying on it.

# Ketvoice 2.11.0 — imported media edits, Sonic Canvas & offline capsules

**Mobile/tablet and Quest · versionCode 20**

## Edit imported songs

As the verified publisher, open an imported song's menu → **Modifier l'audio ou la pochette**. Replace its audio, artwork, or both. Other catalog songs cannot be edited. Audio stays limited to 25 MB and artwork to 4 MB; rights confirmation remains mandatory.

The server verifies the confirmed publishing mailbox and record ownership, rejects spoofed fields, and detects concurrent edits. New versioned Storage paths avoid stale CDN content. Track IDs and lyrics are preserved; check lyric synchronization after changing a recording. Old server media is retained rather than automatically deleted.

The online player checks the current imported revision and uses revision-specific stream-cache keys. Existing offline downloads remain unchanged and must be explicitly downloaded again for updated audio.

## Canvas controls

- **Activer les Canvas vidéo** disables video playback and future Canvas video downloads, including explicit song downloads. Saved videos are not deleted.
- **Sonic Canvas** is independent and **off by default**. It uses coarse low/mid/high energy from actual decoded playback PCM to drive artwork-coloured background gradients. No microphone, audio recording or network telemetry is used.
- Pause, backgrounding and reduced motion stop reactive analysis. Unsupported output paths remain static; no fake beat or voice-detection animation is generated. Physical-device timing/performance is not guaranteed.

## Offline capsules

Downloads → **Préparer une capsule hors ligne**. Choose duration and a file budget, optionally include real home selections, inspect the preview and deselect unwanted songs before preparing.

Favorites are prioritized, then known listening/catalog choices. Downloads are sequential and never evict or replace existing files. Audio, available lyric sidecars and small independent artwork files are bounded by the capsule budget, excluding shared playback/image cache. No Canvas videos are fetched for a capsule. Duration/size estimates and unavailable sources can leave a partial selection; only actual saved files are shown ready. Keep Ketvoice open during preparation. Cancellation preserves saved media.

**Ketogether/group listening has not been added.** Its implementation awaits the user's explicit decision. Existing single-device Wi-Fi handoff stays unchanged.

## Validation

- **110 JVM tests and 12 Android Compose tests pass per flavor**, zero failures; the same suites run for mobile and Quest.
- Device checks use an Android 15 emulator; Quest layout runs at 1280 × 800 dp landscape. PCM tests verify silence, frequency differences, stereo phases and unchanged output bytes.
- Lint: **0 errors**, 137 warnings, 8 hints per flavor. Both release builds, signatures, ZIP integrity and 16 KB alignment checks pass. Existing Android Debug development certificate retained; not a Play Store or Meta Store identity.
- Credential scan: **0 findings across 1,164 source/archive entries**, including the legacy deny list.
- Broker tests: 21 existing cases and 23 imported-edit cases with mocked Auth/database/Storage; 3 live health/auth-denial checks without uploading or modifying real media. `ketvoice-content` v4 deployed with JWT verification enabled; no schema change.
- No real mailbox-owner edit, full live provider capsule download, physical Quest or FPS guarantee is claimed. See `NOTES.md` and `validation.json` for details and the pre-existing Supabase security advisory.

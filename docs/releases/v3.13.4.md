# Ketvoice 3.13.4

![Ketvoice](https://raw.githubusercontent.com/Tysnnn23/Ketvoice/main/ketvoice-banner.png)

## Discord: presence without the OAuth loop

- The primary action is now **Enable Discord presence**: Ketvoice connects to the
  Discord app installed on the phone and publishes the listening activity. There is
  no consent page, no redirect and no browser hand-off, so the loop cannot happen.
- If the Discord app is missing or signed out, the panel says so instead of waiting.
- Account linking remains available as an optional secondary action for users who
  want an explicitly linked account; the presence mode stores nothing on the device
  and still shows the track, artist, cover, elapsed timer and the two buttons.
- Presence still clears on pause, stop, disconnect or opt-out.

## Lyrics flow

- Backing vocals no longer reserve a permanent gap: the extra row is created only
  **200 ms before** the back starts, then collapses after it ends.
- An unfinished line keeps filling while the next line begins, and a long back is
  allowed to finish after the following line has started. Nothing is cut off when
  paragraphs overlap.
- The karaoke glow was reworked: a permanent soft halo on the active line, a wider
  bloom on sustained words and a softer glow on the line that is finishing.

## Equalizer

- The equalizer dialog now draws a smooth glowing response curve of the five band
  gains, with the device's real bands and the reset action added in 3.13.2.

## Validation

- Unit tests, release builds and lint run for both variants.
- **Not device-validated**: presence through the local Discord app, the lyric
  overlap and the new glow need an owner check on a physical phone. The third-party
  lossless provider remains expired; MP3 fallback from 3.13.3 is unchanged.

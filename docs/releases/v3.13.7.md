# Ketvoice 3.13.7

![Ketvoice](https://raw.githubusercontent.com/Tysnnn23/Ketvoice/main/ketvoice-banner.png)

## Lyric glow, Apple-Music style

- There is no permanent halo anymore. The sung text is a plain white fill; only a
  note that is actually held (650 ms or longer) blooms, and the bloom grows with
  the note length.
- This applies identically to line, word-by-word and syllable timings: quick
  syllables stay clean, long syllables and held words glow one at a time. The
  glow never covers a whole line.

## Discord

- **Activer via l'app Discord** now actually opens the Discord app, waits for it
  to start, then connects the local presence session. A retry does the same.
- If the Discord app is missing, the panel says so explicitly instead of silently
  doing nothing. The manifest declares a `com.discord` package query so Android
  11+ can resolve the app.
- The advanced section shows the OAuth2 redirect to register:
  `discord-1566454532890820668:/authorize/callback`. Your Developer Portal had no
  redirect configured, which is exactly why the account-link page could never
  come back to Ketvoice. Presence through the app and the pasted OAuth2 token do
  not need that redirect; the token section remains the fallback.

## Validation

- Unit tests, release builds and lint run for both variants. No phone, Quest or
  accelerated emulator was available: opening Discord, the presence connection,
  the new glow and the album Canvas playback are **not hardware-validated**.

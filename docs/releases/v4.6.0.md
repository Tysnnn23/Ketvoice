# Ketvoice 4.6.0

![Ketvoice](https://raw.githubusercontent.com/Tysnnn23/Ketvoice/main/ketvoice-banner.png)

## A shared native material

- The existing Kyant Backdrop and Android AGSL renderer remain. Visual tokens
  now define the shared palette, typography, spacing, radii, motion, elevation
  and core glass parameters. No Apple-proprietary fonts are bundled.
- Floating controls use the actual captured backdrop where supported. API 31–32
  use blur, a legibility veil and a restrained highlight without claiming AGSL
  refraction. Reduced motion and low-memory devices use a cheaper blur path;
  disabled blur, high-performance mode, opaque mode and unavailable independent
  backdrops use a readable static fallback. Captured content never samples itself.
- Adaptive contrast keeps labels legible over bright and dark content. The
  slider in Appearance adjusts the glass tint continuously, updates the live
  preview, persists on release and restores the original value when cancelled.
  Clear, Frosted and Opaque modes remain available.

## Navigation and player

- The separate mini-player, navigation capsule and search button are retained.
  Their transitions use a shared spring, and compact layout depends on the actual
  available pane rather than the full device width. Mini transport controls have
  48 dp targets; small panes avoid overlapping navigation and search.
- The previously restored cover-first player layout remains. Floating track and
  playlist sheets use the shared material and expose their actions independently
  to accessibility services. The reverb control uses the app's custom slider
  while retaining the same audio control and persisted values.
- Playing bars stop their animation when playback is paused or reduced motion is
  active. Clean timed lyrics, backing vocals, Canvas, player gestures and the
  opt-in Stats info remain. The Quest 2D landscape layout remains unchanged.

## Settings and collection pages

- Settings retain their existing categories and options. Choice, accent, secret
  and glass-preview presentations use adaptive bottom sheets. The tint slider
  supports accessible progress, keyboard arrows and right-to-left pointer input.
- The equalizer and single-device Wi-Fi handoff dialogs use the same sheet and
  switch language. The existing explicit accept/refuse consent remains required;
  no handoff or audio processing logic is changed. Discord token entry remains
  password-masked and the existing presence consent callback is unchanged.
- Album compact actions reserve their space as the header collapses. Playlist
  headers blend title state continuously and use the available cover colour
  without a duplicate blurred-artwork pass. Reordering, unresolved entries,
  sharing, import/export, rename and deletion remain.
- Explorer categories use a contrast-protected matte surface and a layout that
  adapts to large fonts. Artist compact actions do not jump into the header, and
  Home actions use larger touch targets. Existing content and provider calls are
  retained; no new audio engine or publication authorization is introduced.

## Validation limits

The release metadata records unit tests, host/software fixtures, lint, signatures
and explicit validation limitations. Host Skia screenshots are not physical
phone or Quest screenshots and cannot validate actual GPU blur/refraction. Real
installation, hardware performance, frame rates, keyboard/gesture feel and live
provider or Discord sessions require device testing. No frame-rate guarantee or
unmeasured cost-saving percentage is claimed.

Some secondary legacy dialogs still use Material components, including the
offline capsule and publisher/account flows. The
"no default-looking components anywhere" criterion is therefore not yet fully
met; these flows have not been rewritten or claimed as device-validated.

The existing language-selection behaviour is unchanged and eleven interface
languages remain bundled. Karaoke, Canvas, existing playlists/downloads and
verified-owner server authorization are retained. Group listening remains deferred.

# Ketvoice 3.12.0

![Ketvoice](https://raw.githubusercontent.com/Tysnnn23/Ketvoice/main/ketvoice-banner.png)

## Player and Canvas

- Restore the legacy normal Canvas scene: full artwork-region sizing, FIT video
  and the shared bottom dissolve, without the smaller rounded inset video.
- Restrict fullscreen eligibility to verified portrait 9:16 clips. Square,
  landscape and other portrait formats cannot enter it; Quest stays landscape 2D.
- Give three-dot action sheets real sampled liquid glass, with separate backdrop
  layers to avoid self-sampling. Keep readable opaque fallback sheets when glass
  is unavailable or disabled in performance/accessibility settings.
- Add a real adjustable Reverb effect to the track menu. Damped stereo room
  processing runs in Media3's PCM audio path, with smoothed control changes and
  an off-by-default setting that survives restart.

## Sources and downloads

- Add optional Progressive quality under Playback. Start with the first resolved
  stream and prepare a higher-quality decoder independently in the background.
  Switch only after readiness, duration compatibility and position alignment;
  timeouts, errors, seeks and track changes retain/cancel the candidate safely.
  This is a same-track quality upgrade, not an automatic mix between songs.
- Correct custom download endpoints that return JSON metadata rather than audio,
  retain distinct download URLs and preserve alternative source candidates.
- Accept valid initial HTTP 206 responses starting at byte zero while continuing
  to reject wrong ranges, partial files and non-audio downloads.
- Show live circular download progress on Home recent, carousel and featured
  artwork, and on artist/playlist track rows.

## Profiles and artwork

- Add opt-in Fanart.tv artist logos with automatic MusicBrainz resolution,
  original colors/transparency, attribution and normal-name fallback. The provider
  credential is stored only on the server, never in the app or APK.
- Refine playlist artwork sizing, background glow, collapsed titles, contrast,
  duration, shuffle access and current-track highlighting. Keep unresolved tracks
  and editing/reordering available. Add album explicit-content identification.
- Preserve French defaults, all eleven interface languages, reduced motion,
  karaoke, owner-only publication permissions and automatic release/update banners.

## Known external blockers and validation limits

- Live checks found the configured lossless provider returning HTTP 410 with an
  expired-access indication. Its broker currently answers 404 for those streams.
  This release cannot renew third-party access; it does not claim restored FLAC
  availability. Two sampled MP3 streams returned valid HTTP 206 audio data.
- Discord linking/presence is **not included**: the official Android SDK supports
  it, but a registered Ketvoice Discord application with Social SDK access and
  callback configuration is still required. No linked account or live presence is
  simulated. The requested download/listen buttons remain pending that setup.
- Host tests and synthetic audio fixtures are not physical listening, hardware
  video-decoder, GPU-performance, signed owner-session or real APK-upgrade tests.
  The supplied validation metadata distinguishes executed checks from pending ones.
- Android's installation confirmation remains required for app updates.

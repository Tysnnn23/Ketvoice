# Ketvoice 3.0.5 — Studio e-mail return

**Mobile/tablet and Quest · versionCode 30**

- Open `C:\Users\Yanis\Documents\Ketvoice Studio.html` on the computer, or
  use the hosted Studio at
  `https://tysnnn23.github.io/Ketvoice/admin/ketvoice-admin.html`.
- When the owner requests a login link from the Studio, clicking that e-mail
  link returns to the hosted Studio in the browser and completes sign-in.
  A link requested from the mobile app still returns to `ketvoice://auth`.
- The free-tier Supabase e-mail template cannot be changed to deliver a code
  without configuring custom SMTP or upgrading. This version keeps link-based
  authentication rather than pretending to send a code.
- Music playback and artist layouts are unchanged from 3.0.4. The HTML page
  never grants publication rights without server-side owner verification.

Browser redirect, navigation and publication controls were checked with
mocked credentials. Live owner e-mail delivery, opening the link and device
installation/visual checks require the owner and were not performed here.

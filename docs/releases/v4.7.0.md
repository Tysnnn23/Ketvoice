# Ketvoice 4.7.0

![Ketvoice](https://raw.githubusercontent.com/Tysnnn23/Ketvoice/main/ketvoice-banner.png)

## Optical glass, not a painted blur

- Directional edge reflections no longer illuminate both sides equally. Refraction, a restrained inner caustic and depth shading are evaluated by the existing AGSL material against captured content.
- Pressing a glass button changes the sampled edge displacement and optical normal, with an elastic release. The glyph and the touch target stay stable.
- Sliders capture their own independent track behind the thumb, so the thumb can refract its track without sampling itself. Dragging updates the thumb immediately.
- Static fallbacks have quieter highlights and less opaque floating controls. Android 12, reduced-motion, low-memory and performance-mode paths remain explicit fallbacks; they are not advertised as AGSL.

## Library and downloads

- The library now uses an editorial title, useful counts, clean grouped shortcuts and consistent outline icons instead of mismatched filled glyphs. Search, views, playlist import/pinning, local albums and multiple selection remain available.
- Floating library and download actions sample the scrollable content behind them. Filters have animated selection and proper accessible tab states.
- Downloads separate transfers from playable offline files, with an understated storage summary, matte rows and the existing real progress/pause/resume/retry controls. Batch deletion still requires confirmation.

## Albums and settings

- Album artwork blends into an image-derived surface without a white fog or hard separator. Adaptive portrait and landscape layouts retain Canvas, metadata, play/shuffle, downloads, refresh and sharing.
- Album actions use a separate captured artwork layer; top controls sample the scrolled page. Track rows and appearance changes animate while respecting reduced motion.
- Settings use restrained grouped cells, consistent 24-pixel outline icons, readable supporting text and accessible choice states. The glass preview remains live, adjustable and persistent, with cancel restoring the original tint.

## Preserved

The restored navigation and cover-first music-player arrangement, synchronized karaoke, all audio/provider behavior, local files, source priorities, eleven interface languages and the Quest landscape 2D player remain. AutoMix is not restored and group listening is not added.

## Validation boundaries

Host tests and software-rendered fixtures are not physical-device or hardware-GPU validation. No physical phone or Quest was connected. Emulator installation failed because the disk had insufficient free space. Device refraction calibration, gesture feel, measured frame rate, audible Tidal playback, Discord authorization and USB bit-exact output are not claimed.

The signed APKs retain the existing Android debug signing identity for update compatibility; this is not a private production certificate. Actual completed test/build/signature/checksum results are recorded in the accompanying validation metadata.

# Ketvoice 3.13.6

![Ketvoice](https://raw.githubusercontent.com/Tysnnn23/Ketvoice/main/ketvoice-banner.png)

## Discord, moved and diagnosable

- The Discord panel now lives in **Settings → Compte** instead of the profile
  overlay, next to YouTube Music.
- Presence through the installed Discord app is still the default. A connection
  attempt that never reaches Ready now times out with an explicit message instead
  of leaving the panel spinning, and the last SDK log line is shown under the
  error so a silent failure becomes readable.
- An optional **OAuth2 token** connection was added (advanced section). It only
  accepts a bearer token issued for the Ketvoice Discord application; regular
  Discord user tokens are rejected by the SDK. A rejected token is discarded
  instead of being restored on every launch. The older OAuth2 account-link flow
  remains available in that same advanced section.

## Lyrics

- The glow is back to the older soft halo, but only on the active lead line at
  low intensity. Only notes held for at least 850 ms get the real bloom and a
  thicker contour; ordinary words, syllables and other lines stay clean.
- Word highlights are now aligned against the rendered line before being drawn.
  Foreign-language providers that segment CJK text differently, add spaces or
  ship mismatched word tokens no longer light the wrong glyphs; if the mapping is
  impossible the whole line is highlighted as one segment.

## Artist pages

- The hero uses a blurred copy of the photo as ambience, so wide banners no
  longer sit between two flat bands, and portraits fill the frame without an
  arbitrary face crop.
- Artist avatars in search and related artists get a hairline ring and an initial
  fallback instead of an empty grey disc.

## Artist logos

- The broker now paces MusicBrainz to one request per second instead of failing
  the whole lookup with a 429, raises the minute budget and recovers faster after
  an upstream rate limit. Back-to-back logo lookups work again.

## Ketvoice Studio

- The edit form has a **Canvas de l'album (MP4)** field. One upload can be applied
  to every title of the album; the app downloads and plays that video instead of
  resolving a Canvas from the provider. A new `canvas_path` column and the
  deployed `ketvoice-content` function implement it, and the album picker shows
  whether an album already has a Canvas.

## Validation

- Unit tests, release builds and lint run for both variants. No phone, Quest or
  accelerated emulator was available: the Discord connection, the new glow, the
  hero framing and the album Canvas playback are **not hardware-validated**.

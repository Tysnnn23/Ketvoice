# 🎧 Ketvoice 3.0.0-Beta2

Another beta polish round for the 3.0.0 era — stability first! 💪

## 🐛 Fixes
- 🛡️ **Artist page crash fixed** — tapping an artist (from search, the player, or related artists) no longer crashes. All network/JSON/loading errors are now caught gracefully with a clean "Retry" screen instead.
- 🖼️ **Cover enrichment hardened** — background artwork fetching can no longer take the app down.

## ✨ Improvements
- 🧹 **New setting: "Clear image cache"** — found in Settings → Storage. One tap purges cached album covers & artist photos (they re-download on demand).
- 🎚️ **Nicer scrub bar** — the progress bar now thickens with a white thumb while you drag, for sharper touch feedback.
- 🌐 Settings text polish across languages.

## 📦 Assets
- `Ketvoice-3.0.0-Beta2.apk` — phones & tablets
- `Ketvoice-3.0.0-Beta2-Quest.apk` — Meta Quest

> ⚠️ Beta build: expect rough edges, and please report any crash with your device model! 🙏

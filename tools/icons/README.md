# Launcher icons (6.0.0 Beta 4)

The owner's four iOS 27 style images (`source-*.jpg`, generated by the owner with gpt-image-2.5-sunburst
from the glass K) are turned into transparent glass by `unmatte.py`, then into adaptive-icon layers and
picker previews by `build_launcher.py`:

    python3 tools/icons/unmatte.py tools/icons/source-glass.jpg  out/glass.png  dark
    python3 tools/icons/unmatte.py tools/icons/source-light.jpg  out/light.png  light .06 .5
    python3 tools/icons/unmatte.py tools/icons/source-tinted.jpg out/tinted.png dark
    python3 tools/icons/unmatte.py tools/icons/source-clear.jpg  out/clear.png  light .08 .3 .14 21 cut
    python3 tools/icons/build_launcher.py out app/src/main/res
